# The Honest Mockument — live demo

**A mockument is half mock-up, half document.** Something you can move through like the app itself,
carrying the writing that explains what each part means, where it came from, and what nobody has
decided yet. It looks like the app, and it tells you which parts are real.

### → https://vguyaux.github.io/mockument-demo/

Two things to look at:

- **The sample mockument** — a worked example you can walk. Switch role and state on any page,
  turn on the honesty overlay to see how much of the screen is actually agreed, and click any element
  for its record, its source and its open questions. The example app is deliberately generic — an
  internal request-and-approval app — so it can be swapped for any real product.
- **The method** — *The Honest Mockument* in full: the model, the representation, the twenty-two
  blocks of a page, the data ladder, the readiness gates, and the machine-readable schema. Plus a
  companion document on the data layer.

Part of the [Honest framework](https://honestframework.software/).
