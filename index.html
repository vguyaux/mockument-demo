05How to read a mockument page
The five markers

required an answered requirement supports it.

proposed drawn to make the mock concrete; nobody has accepted it.

unanswered a decision is missing, and it names who owes it.

observed noticed while walking through; not yet a decision.

out of scope deliberately not answered here.

Three ways to use this

Walk it. Use the menu as if it were the app. Switch role, device and state on any mock.

Question it. Turn on the honesty overlay. Everything outlined in amber or pink is not yet agreed.

Build from it. Each page ends with a build contract and a machine-readable island. Hand that to whoever — or whatever — writes the code.
